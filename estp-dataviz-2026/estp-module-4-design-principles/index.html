Five key takeaways

Five different jobs, one design system

The steps above are not separate style rules. They work together to decide what the reader sees now, what stays quiet and what can wait.

1

Hierarchy

Create a clear reading order before adding decoration.

2

Emphasis

Make only the analytically important elements prominent.

3

Comparison

Use alignment, ordering and common scales to reduce mental work.

4

Interaction

Reveal detail or subsets only when they answer a question.

5

Structure

Show some dimensions, select some and reveal others progressively.

One small design comparison

Supporting elements should stay supporting

Typography, gridlines, labels and colour all participate in hierarchy. The useful question is how much attention each element deserves.

EVERY ELEMENT IS LOUD

Population by age group, 2023

Heavy gridlines, repeated labels and equal typographic weight make the reader process the furniture before the pattern.

Nothing statistical changes. The improved version simply asks supporting elements to claim less attention.
