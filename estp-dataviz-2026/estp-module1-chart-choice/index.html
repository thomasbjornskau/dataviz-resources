Chart choice is a reasoning problem

Choosing the right chart

There is no universally best chart. The useful question is which visual structure makes the statistical relationship easiest to see.

data→question→encoding→chart form

Five takeaways

Think about what the reader must see

1

Start with the analytical task, not the chart type

Comparing, showing change, distribution, relationships, composition or flow each call for different visual structures. Name the task before naming the chart.

comparechangedistributionrelationshipcompositionflow
2

Chart types are combinations of visual encodings

Position, length, area, colour, connection and direction are the building blocks. Understanding these is more useful than memorising a list of chart types.

Position Length Area Colour Connection Direction
3

Use the simplest chart that preserves the insight

Bar and line charts are powerful because readers understand them quickly. More specialised charts should earn their complexity by revealing a structure that simpler charts cannot.

familiar structure→faster comparison
4

Specialised charts reveal structures that classic charts cannot

Treemaps can show hierarchy, Sankey diagrams flow, heatmaps patterns across two dimensions, and dot plots compact comparisons. Use them when the data genuinely contains that structure.

Treemaphierarchy → area Sankeyflow → connection + width + direction Heatmaptwo dimensions → position + colour Dot plotcomparison → position
5

The best chart is the one that makes the relevant comparison easy

A technically correct chart can still be a poor choice if the reader has to work hard to see the pattern, difference or relationship that matters. Correctness is necessary; perceptual effort still matters.

What needs to be compared?Make that comparison direct.

Population 1 January · persons

Norway's population, 1951–2026

Population is a stock measured on 1 January. The line connects annual observations so change and continuity are easy to follow.

Why this chart?

Position on a common vertical scale gives accurate values; connection makes the temporal sequence explicit.

Why not the obvious alternative?

A bar chart is valid, but 76 bars place more visual emphasis on individual annual magnitudes than on the long-run trajectory.

Statistical integrity

Population 1 January is a stock. The other main variables in table 06913 are flows during the calendar year. The page never treats them as interchangeable.

Select a building block

A chart form is a convention for combining encodings. The useful question is not merely what the chart is called, but which perceptual channel carries the comparison.

Bar chartposition + length
Line chartposition + connection
Scatter plotposition × position
Treemaparea + hierarchy
Heatmapposition + colour
Sankeyconnection + width + direction
Do not manufacture structure.

Table 06913 has annual totals, not origin–destination migration links and not a hierarchy. A Sankey or treemap would therefore be semantically wrong for this dataset, even if it looked impressive.
