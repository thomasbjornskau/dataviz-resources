Structure comes before emphasis.

Design should support comparison

Make the important comparison visually cheap

The reader should not have to remember one distribution while decoding another. Common scales, identical ordering and aligned baselines turn comparison into perception rather than mental arithmetic.

Which differences can you see without calculating them mentally?

Same values, harder comparison. Separate scale ranges and reversed ordering force the reader to reconstruct the relationship.

Supporting elements should stay supporting

Typography, gridlines and labels are part of the same hierarchy

These are not isolated style choices. Each one decides how much attention a supporting element claims.

Integrate explanation into the visual hierarchy

Place an annotation close to the relevant data, keep it quieter than the main message and use one consistent annotation style. A detached text box creates another object the reader must connect mentally.

Colour as a design system

Categorical colour and highlight colour do different jobs

Categorical colour separates categories that need to remain equally visible. Highlight colour creates hierarchy. Do not assign a different strong colour to every age group when the analytical task is to focus on one.

Colour is one of the strongest hierarchy controls available. Use it sparingly. Labels and position reinforce the distinction, so colour is not the sole identifier.

Accessibility is design

A clear hierarchy should survive without colour, hover or a large screen

Accessibility and information structure often reinforce each other: direct labels reduce legend lookup, larger targets reduce interaction errors, semantic controls clarify purpose, and restrained hierarchy reduces noise.

Module 4

Good design does not make statistics look simpler. It makes their structure easier to understand.

1Create hierarchy before adding decoration. Reading order comes from position, spacing, alignment, type and weight. 2Use visual emphasis selectively. Prominence should correspond to analytical importance. 3Design for comparison with alignment, common scales, meaningful ordering and consistent spacing. 4Interaction should reveal structure or detail. It should solve an information problem, not advertise technology. 5Complexity needs structure. Show some dimensions, compare some, select some and reveal others progressively.
